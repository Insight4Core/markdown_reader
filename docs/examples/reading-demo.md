# A small Markdown example

This is an ordinary `.md` file. Open it in a text editor to see the source, or in a Markdown reader to see the formatted document.

## Start with the essentials

- **Headings** make a long document easier to navigate.
- Lists turn a few ideas into clear steps.
- [Links](https://www.markdownguide.org/basic-syntax/) connect the document to useful references.

> Keep the original file. Choose the view that helps you read it.

## Choose a view

| What you want to do | A useful option |
| --- | --- |
| Check a few words | A text editor |
| Write and preview together | VS Code preview |
| Read a longer document | A Markdown reader |

## A little code

```js
const note = { format: 'Markdown', extension: '.md' };
console.log(`Reading ${note.extension} files`);
```

The file remains plain text. You can return to your preferred editor whenever you need to make a change.
