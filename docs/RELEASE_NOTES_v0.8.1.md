# 知返 0.8.1 / Pyrus 0.8.1

**发布日期 / Released:** 2026-10-01

## 简体中文

知返 0.8.1 让 Markdown 文件可以留在原来的位置，同时更容易开始阅读和整理。

### 新功能

- **直接阅读单篇文件**：从欢迎页打开，或将 `.md`、`.markdown`、`.mdx` 文件拖入应用。首次阅读提示会说明文件仍在原位置。
- **链接外部来源**：将其他位置的文件夹或单篇 Markdown 加入当前知识库。知返保存路径引用，不复制或移动原文件。
- **跨来源阅读与查找**：侧栏、全文搜索、今日回响和知识回响会包含已链接的来源。
- **轻量反馈邀请**：阅读几篇内容后，可自愿分享知返在哪个使用场景帮到了你；不会收集阅读遥测数据。

### 使用方式

1. 在欢迎页选择「打开 Markdown 文件」，或直接拖入一篇文件。
2. 打开知识库后，在首页选择「添加外部文件夹」，或阅读外部单篇时选择「加入当前知识库」。
3. 原文件保持在原位置；来源不可访问时，可移除引用并在之后重新添加。

## English

Pyrus 0.8.1 makes it easier to read Markdown where it already lives, then bring selected files and folders into a knowledge base by reference.

### What's new

- **Open a single note directly** from the welcome screen or drop an `.md`, `.markdown`, or `.mdx` file onto the app. A small first-read prompt clarifies that the original file stays in place.
- **Link folders and individual notes** from anywhere on your drive. Pyrus stores references; it does not copy or move your files.
- **Search and rediscover across sources** with the Explorer, full-text search, Today's Echo, and Knowledge Echoes.
- **Optional, contextual feedback** invites readers to share when Pyrus helped after they have read a few notes. No reading telemetry is collected.

### Getting started

1. Choose **Open Markdown file** or drop a note onto the welcome screen.
2. From a knowledge home, choose **Add linked folder**, or use **Add to this knowledge base** while reading an external note.
3. Your originals remain where they are. Remove a reference if its source is no longer needed, then add it again later if appropriate.
